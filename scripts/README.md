# Command-line scripts

- `prepare_data.py`: convert Dedalus HDF5 trajectories or vector-potential
  arrays to the canonical PHASE `.npy` layouts.
- `compute_statistics.py`: compute train-only normalization statistics.
- `train_tfno.py`: train the previous-study, no-warm-start tFNO baseline.

Feature generation, scOT training, diffusion training, evaluation, and
visualization entry points will be added in later audited batches.
